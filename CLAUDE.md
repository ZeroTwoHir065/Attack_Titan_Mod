# Attack Titan Mod — Civilization VI

## Скилл для создания модов
При работе над этим модом всегда используй скилл `civ6-leader-mod` (установлен в `~/.claude/skills/civ6-leader-mod/`).
Вызывай его через `Skill(civ6-leader-mod)` перед началом работы над любыми файлами мода.
Следуй его правилам баланса, структуры и тестирования.

## Репозиторий
- Remote: https://github.com/ZeroTwoHir065/Attack_Titan_Mod.git
- Рабочая директория находится прямо в папке модов Civ VI — для тестирования достаточно перезапустить игру.
